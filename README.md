# Profile Page Assignment

## What to Build
A personal profile page using only HTML.

## Requirements
- Your name as the main heading
- A short About Me paragraph
- A list of 3–5 hobbies or interests
- A favourite quote wrapped in a blockquote <blockquote>
- A link to a website you like
- At least one image

## Sample Page
-  https://patricia-sigei.github.io/Modara-HTML-Sample-page/

## Submission
- Create your own GitHub repo
- Build your profile page in an index.html file
- Share your repo link
